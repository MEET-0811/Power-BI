# 📊 Final Power BI Project – Sales & Customer Intelligence Dashboard

## 📌 Project Overview
This project focuses on building a **comprehensive, data-driven Power BI dashboard** to analyze:
- Sales Performance  
- Customer Behavior  
- Regional Trends  

The dashboard delivers **actionable insights** using advanced DAX calculations and an interactive design for decision-making.

---

## 🎯 Objectives
- Build a **robust data model (Star Schema)**
- Use **advanced DAX formulas** for KPIs
- Apply **Time Intelligence (YOY, MOM, YTD)**
- Create an **interactive multi-page dashboard**
- Ensure **mobile compatibility**
- Implement **Row-Level Security (RLS)**

---

## 📂 Dataset Tables
The project uses the following tables:

- `Date_Dim`
- `Customer_Dim`
- `Product_Dim`
- `Sales_Fact`
- `Returns_Fact`
- `Region_Dim`
